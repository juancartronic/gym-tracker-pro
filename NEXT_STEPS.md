## 🚀 Próximos Pasos

### 1️⃣ Subir a GitHub (5 minutos)

```bash
# Ir a tu carpeta
cd c:/Users/Juanka/Desktop/gym-tracker-pro

# Ver estado
git status

# Crear repo en GitHub (https://github.com/new)
# Nombre: gym-tracker-pro
# NO inicializar con README

# Conectar y subir
git remote add origin https://github.com/TU_USUARIO/gym-tracker-pro.git
git branch -M main
git push -u origin main

# GitHub pedirá autenticación (usar Personal Access Token)
```

**Más detalles**: Ver `GITHUB_SETUP.md`

### 2️⃣ Usar la Aplicación

```bash
# Opción A: Abrir directamente (sin servidor)
# Abre: c:\Users\Juanka\Desktop\gym-tracker-pro\gym_tracker.pro.html

# Opción B: Con servidor (Node.js)
cd c:/Users/Juanka/Desktop/gym-tracker-pro
npm install
npm start
# Luego en navegador: http://localhost:3000/dashboard

# Opción C: Con servidor (Python)
cd c:/Users/Juanka/Desktop/gym-tracker-pro
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python server-flask.py
# Luego en navegador: http://localhost:5000/dashboard
```
